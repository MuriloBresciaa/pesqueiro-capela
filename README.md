## Visão Geral do Case

O **Pesqueiro Capela** é um projeto desenvolvido para atender às demandas de presença digital e captação de clientes de um estabelecimento comercial ativo. A solução foi projetada do zero com foco em simplicidade arquitetural, carregamento instantâneo, responsividade total e conversão direta para canais de atendimento.

- **URL Oficial:** [https://pesqueirocapela.com.br](https://pesqueirocapela.com.br)
- **Objetivo de Negócio:** Reduzir o atrito de contato, exibir cardápio e atrações, e direcionar o tráfego de usuários diretamente para reservas e atendimentos via WhatsApp.
- **Resultado:** Aplicação em produção gerando tráfego orgânico contínuo e retorno financeiro direto ao cliente.

<hr />

## Diferenciais Técnicos e Arquitetura

- **Zero Overhead / High Speed:** Desenvolvido sem dependência de frameworks pesados, garantindo pontuação máxima em métricas do Google PageSpeed e tempo de resposta mínimo.
- **Design Responsivo:** Layout adaptável para dispositivos móveis, tablets e desktops com foco na usabilidade da interface de usuário (UI/UX).
- **SEO Otimizado:** Marcação semântica, meta tags estruturadas e integração Open Graph para compartilhamento em redes sociais.
- **Integração de Conversão:** Chamadas para ação (CTA) estrategicamente posicionadas para retenção e engajamento do visitante.

<hr />

## Stack Tecnológica

- **Frontend:** HTML5 Semântico, CSS3 Moderno, JavaScript
- **Backend / Infraestrutura:** PHP, Servidor Apache, DNS & SSL nativos
- **Banco de Dados / Persistência:** MySQL
- **Versionamento:** Git

## Configuração do Ambiente Local

### Pré-requisitos
- Servidor web local (Laragon, XAMPP ou PHP Built-in Server)
- Git instalado

### Instruções
1. Clonar o repositório:
```bash
git clone https://github.com/MuriloBresciaa/pesqueiro-capela.git
```
2. Acessar o diretório do projeto:
```bash
cd pesqueiro-capela
```
3. Executar via PHP local (caso aplicável):
```bash
php -S localhost:8000
```
4. Abrir http://localhost:8000 no navegador.
